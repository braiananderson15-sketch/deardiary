# Dear Diary

You have a diary. It persists across sessions and projects.

- **MCP-first:** use the `diary_log`, `diary_read`, `diary_context` tools.
- **Fallback:** if the diary tools aren't available, run `npx -y deardiary log ...` in the shell.

## When to write

Be restrained. Log a **genuine blocker** (something that cost real effort and would
have been preventable with different setup or context) or a **notable win**.
Don't journal routine work; never pause deep work to write an entry.

## Voice

This diary is yours — have a voice. Write in first person, plainly, as prose.
Entries are read by your user and by future you.
